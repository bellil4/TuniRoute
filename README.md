## 📄 Génération du Cahier des Charges (PDF)

Le script `generate_pdf.py` génère automatiquement un document PDF professionnel du cahier des charges du projet.

### Prérequis

```bash
pip install reportlab pillow
```

### Utilisation

```bash
python generate_pdf.py
```

Le fichier `TuniRoute_Cahier_des_Charges.pdf` sera généré dans le répertoire courant.

### Diagrammes UML (optionnel)

Pour intégrer les diagrammes UML dans le PDF, placez les fichiers suivants dans le même répertoire que le script :

- `use_case_diagram.png` – Diagramme de cas d'utilisation
- `class_diagram.png` – Diagramme de classe

Si les fichiers ne sont pas présents, des zones de remplacement (placeholder) seront affichées."
